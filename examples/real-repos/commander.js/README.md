# tj/commander.js

12 months of review history (Jun 2025 – Jun 2026), 535 comments.

**0 rules either way.** Nearly all review comes from one maintainer, so
nothing clears the default "≥ 2 reviewers" bar. That is the bar working
as intended: a single person's preferences aren't necessarily the
project's conventions.

The skill reports what's below the bar, for example "PRs shouldn't
update `CHANGELOG.md`" and "keep character checks (`str[0] === c`)
rather than `startsWith`". Ask Claude to relax the bar (e.g. "include
single-reviewer conventions") if you want those as rules for a
single-maintainer project.
